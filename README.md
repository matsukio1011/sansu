# 計算修行道場 (分数・整数マスター)

小中学校向けの算数計算トレーニングWebアプリです。
分数×整数、整数×分数の計算を素早く行い、答えが「整数」になるか「分数（既約分数）」になるかを判断して解答する修行ゲームです。

## 主な機能
- **修行コース選択**:
  - `すべて (ランダム)`: 1/10 と 1/100 がランダムに出題
  - `× 1/10 (十分の1)`: 1/10の掛け算に特化した集中コース
  - `× 1/100 (百分の一)`: 1/100の掛け算に特化した集中コース
- 整数 or 分数の直感的な2択ステップ選択
- 上下型の直感的な分数入力UI
- 約分忘れを検知して指導するフィードバックシステム
- 連続正解（コンボ）や正解率のリアルタイム表示
- Web Audio APIによる効果音
- 全画面表示モード対応
