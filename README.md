# 算数トレーニング道場 (sansu)

Webブラウザ上で手軽に学べる小学校・中学受験・基礎計算トレーニングアプリ集です。  
PC画面でスクロール不要（1画面完結）でテンポよく反復練習ができる設計になっています。  
全アプリで**ダークモード**および**全画面表示（Fキー / ボタン）**に対応しています。

## 収録アプリ一覧

1. **アプリ選択ポータル (`index.html`)**
   - 全アプリへのハブ画面。キーボードの `1`〜`7`、矢印キー＋`Enter`で素早く起動できます。

2. **計算修行道場 - 分数・整数マスター (`seisubunsu.html`)**
   - 分数×整数、整数×分数の計算を素早く行い、答えが「整数」になるか「分数（既約分数）」になるかを判断して解答する修行ゲーム。
   - コース選択: `すべて (ランダム)` / `× 1/10` / `× 1/100`。
   - 上下型の直感的な分数入力UI、コンボ演出、約分忘れ検知フィードバック。

3. **分数 約分マスター (`bunsu.html`)**
   - 分子・分母が1〜50の真分数が約分できるか瞬時に見極める判定トレーニング。
   - 2や3の約分から大素数まで。初級モード、3の倍数特化モード、早押し判定。

4. **倍数マスター (`baisuu.html`)**
   - 2, 3, 4, 5, 6, 9 の倍数を瞬時に見分ける判定トレーニング。
   - 初級（2択・指定数またはランダム）および総合（4択）の2モード。
   - 2桁〜5桁の桁数選択、倍数判定早見表付き。

5. **帯分数マスター (`taibunsu.html`)**
   - 仮分数を正しい帯分数に直す計算練習トレーニング。
   - 純粋な仮分数だけでなく、整数部分を含む仮帯分数（例: $2\frac{7}{5}$）への対応や分子・分母の桁数カスタマイズに対応。
   - 既約分数判定・詳細ステップ解説・キーボード解答（`1`〜`4`）対応。

6. **速さマスター (`hayasa.html`)**
   - 速さ・道のり・時間の関係（「はじき」「みはじ」）を瞬時に見抜く暗算特訓トレーニング。
   - 基本問題／標準問題、求める量（速さ・道のり・時間）、答えの形式（整数・小数・分数）を選択可能。
   - 速さ表記切替（時速km ↔ km/時）、公式ヒント表示切替、全180問収録。

7. **ドパ倍数 (`dopabaisuu.html`)**
   - ポップで爽快なビジュアルとWeb Audio効果音・BGMを搭載した倍数判定トレーニング。
   - 初級2択／総合4択、桁数選択（2〜5桁）、じっくり練習モード＆60秒アタックモード。

8. **割合・暗算アニマル道場 (`wariai.html`)**
   - 小学校のつまずき単元「割合」をテンポよく暗算できる特訓アプリ。
   - 3段階難易度（ウサギ・コリー・トラ）、割合表記切替（％・歩合・小数・分数）。
   - 目標連続正解達成で動物お祝い絵イラスト演出。

## 特徴

- **1画面完結UI**: PC画面スクロール不要のレスポンシブ配置。
- **全画面表示**: ヘッダーの切り替えボタンまたは `F` キーで全画面表示のON/OFFが可能。
- **ダークモード**: ヘッダーのテーマボタンでライト／ダークをワンクリック切り替え。
- **キーボード完全対応**: 数字キー、矢印キー、Space / Enterキーで素早くテンポよく操作可能。
- **スタンドアロン動作**: サーバー構築や事前ビルド不要。HTMLファイルを開くだけですぐに動作します。
